A one-line museum placard for the office fridge, written as if it were an ancient artifact, for make.fun's "Office Artifacts: The One-Line Placard Contest" bounty. `main.py` writes the entry to `/output/entry.txt`.

The entry:

> Cold Storage Vessel, c. 2019. White steel, still humming. Gift of Facilities. One container inside predates the building. Do not open. Do not ask.

## Run it

```sh
python3 main.py
```
